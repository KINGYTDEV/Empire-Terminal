# Empire-Terminal

A minimalist, mobile-friendly tap-to-earn tycoon game built with HTML, CSS, and JavaScript.

About

Start with a small amount of capital, generate revenue, buy businesses, upgrade your income, and build your own business empire. Your decisions shape your company's story.

Features

- Tap-to-earn gameplay
- Business purchases and passive income
- Story-driven choices
- Upgrades and achievements
- Automatic local saving
- Limited offline earnings
- Mobile-friendly terminal-style interface
